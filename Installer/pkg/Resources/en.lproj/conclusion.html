Install a network (LAN) printer
  1. On first launch the welcome assistant greets you: on its Find Printers page, click Install… on Install network printer (if @APP_NAME@ was set up before, the Install Printer assistant opens directly). Printers on your network are found automatically; you can also enter the IP address (port 9100).
  2. @APP_NAME@ detects model, resolution and printer language by itself – click Install.
  3. Done: the printer appears in System Settings › Printers & Scanners and in every app’s print dialog, printing through the LabelWerk driver.

No assistant on screen (e.g. after installing from Terminal or after an update)? Open @APP_NAME@ from the Applications folder and choose File › Install Printer…. No printer at hand? Choose File › Add Demo Printer.

Without the app: macOS System Settings

Printers & Scanners › “+” › IP, enter the address, protocol HP Jetdirect – Socket, and pick the driver “Zebra model (dpi) - LabelWerk” under Use.

Many printers or Macs (IT)

If selected, lwctl is available in Terminal: lwctl install --printer tcp://192.168.1.50 detects the model and sets up the printer; lwctl help install lists all options, and lwctl discover finds printers.

Having trouble? The “Installation” documentation and the app’s Drivers & Queues › Diagnostics section help with troubleshooting (filter permissions, CUPS logs).
